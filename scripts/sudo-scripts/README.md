These scripts are for use in `/standardebooks.org/config/sudoers.d/*`, because since Ubuntu 26.04 introduced the `sudo-rs` alternative to `sudo`, wildcards are no longer supported in `sudo` permissions stanzas. We copy these files to `/usr/local/libexec/standardebooks/` and `chown` them to `root` because the scripts are group writable; if sudoers pointed directly at the scripts, a user in the `se` group could replace it and have `sudo` run their code as `root`.
